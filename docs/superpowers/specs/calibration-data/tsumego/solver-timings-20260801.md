## 既知の観察

- **答えがコウのケース（K/V/V2/F2/L）でクラスと n\* が直接出る**（現行の構造検出の
  代理指標が全部不要になる）: V/V2 は KO/ko1（白先劫=コウダテ1つ必要）、K/L は KO/ko0。
- 現行の既知限界 O（KataGo の value 誤読で 12000visits でも v1）は 3.3 秒で厳密解。
- 大 region（P=36/23、T=60/33、U=63/39、W=49/33、I=63/35、R=78/49、G2=80/52）は
  240 秒では足りない。P1 は「速度は問わない」ので長予算（1800s/solve）で追試（下記）。

## 長予算ラン（1800 秒/solve）

**W@0/W@2・I@0・R@0・T@0/@2・U@0・G2@2・H@4・J@10・P@2 はいずれも 1800 秒でも未解決**
（Benson 早期打ち切り復帰・probe の Benson 除去〈下記〉後の W@0 単発 600 秒でも同じ）。
空点 23〜52 の反証系（「無条件では生きられない/殺せない」の証明）が現行カーネルの
探索技術の限界域。実運用ではこれらは solver_time_limit_ms 打ち切り → 現行経路への
フォールバックで、**現行の挙動が保存される**（G5。ソルバの「以後即フォールバック」
フラグにより2手目以降の待ち時間も増えない）。

- L@0 は OPT 予算 30 秒でも同格タイ（L5/J6 とも厳密に KO/ko0）が plies で決着せず ALT のまま。
  GUI では §6.5.1-3 の KataGo policy タイブレーク（実装済み）が J6 を選ぶ見込み（要 GUI 確認）

## カーネルの追加最適化（2026-08-01・値は不変）

- **Benson 早期打ち切りを復帰**（cheap-two-eyes → ミス時のみ Benson、位置キャッシュ付き）。
  一点眼2つの形しか見えない cheap 判定だけでは、広い眼空間の生き証明が
  「埋め尽くし」の深い探索に爆発する（§6.3-2 の設計どおり）
- **probe（子見積もり）の終端判定から Benson を除去**。probe は1ノードあたり子数
  （〜30）回走るので、そこに Benson を置くと 1 ノード 30 Benson になる。見逃した
  終端は展開先ノードの入口で捕まるので健全
- ts_call を 512MB スタックの専用スレッドで実行 + 再帰深さ上限 1024

## P1 の判定（意思決定点）

- **方式（クラスの直接判定）は実証された**: 解けた 11 手番はすべて期待手と一致し、
  コウの細分（ko0=黒先劫 / ko1=白先劫 / ko2〜3=ヨセコウ）まで一致。特に **case Q
  （現行の既知限界=準備手の value 誤読）を 11 秒で突破**、case O（探索崩壊）3.3 秒、
  case F（壊れた盤）を「解無し」と正しく裁定
- **スケールは未達**: 空点 23 以上の反証系が分オーダーでも終わらない。次段階は
  眼形テーブル（§6.3-3）・λ探索（§6.1）・領域分割（§14 Niu & Müller）
- 実運用（solver_time_limit_ms=30000）では 20 ケース中 10 ケース前後をソルバが厳密解で
  即答し、残りは現行経路へフォールバック＝**現行より悪くなるケースは構造的に無い**
