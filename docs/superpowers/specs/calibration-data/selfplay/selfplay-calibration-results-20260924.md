  19.8% / 0.86 目で、目標 29.1% / 0.96 目より 9.3pt 低い。この差は主に手数の問題で、τ では直せない。ハーネスの局は
  実戦より長く、85 手以降に実戦なら投了で終わっていた局面の長いヨセ・ダメ詰めの手が入る（終盤の区間に入る手そのものが違う）。

  上げれば、すでに目標より高い序盤（29.3% vs 26.7%）もさらに上がる。直すのは投了モデルの方（length モデル＝実戦の手数 L）で、
  校正し直した後に区間の形（中盤・終盤）をもう一度見る
