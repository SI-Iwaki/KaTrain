## 判断（2026-09-24）

- 採用したプール: rank_1k, rank_1d, rank_3d・τ 1.0（score 2.41）。局平均 22.5% / 局間 SD 9.4pt / 損失 1.75 目（目標 23.1% / 6.5pt / 1.77 目）。段位の組は lead の投了モデルでの校正（`selfplay-calibration-results-20260924.md`・score 4.07）と同じ
- 区間の形（採用プールの中盤 24〜84 手）: 相手 21.4% / 2.46 目（目標 18.2% / 2.43 目）。τ の再校正: しなかった（|21.4% − 18.2%| = 3.2pt ≤ 5pt・|2.46 − 2.43| = 0.03 目 ≤ 0.5 目で、どちらも判定の範囲内）。序盤（24 手未満）は 28.3% / 0.48 目（目標 26.7% / 0.56 目）
- 終盤の区間（85 手以降）: 採用プールの相手は 13.4% / 1.33 目（段位ごとの値の平均。3段位の手をまとめると 14.1% / 1.64 目・149 手・24 局中 9 局）で、目標 29.1% / 0.96 目（実戦 79 手・18 局中 6 局）より約 15pt 低い。lead の投了モデルでの校正（19.8% / 0.86 目）より離れた＝手数を実戦に揃えても終盤の差は縮まず、前の結果 md の「差は主に手数の問題」という見立ては当たらなかった。τ では直さない: τ を下げれば終盤は上がるが、中盤（+3.2pt）と序盤（+1.6pt）はすでに目標より高く、さらに離れる（中盤は実戦の相手の手の 61%＝434 / 715 手）。終盤は相手の手の 1〜2 割（実戦 11%・ハーネスのプール 14%）なので局平均への影響は小さいが、終盤の区間を読む比較（ヨセの判断を変えるアーム）では相手の忠実度の限界（spec §11）として読む。相手の終盤の top5 は 49% で、最善手の近くは打っている。AI 側の終盤もハーネスは 59.7%（実戦 67.5%・どちらも手をまとめた値）と低い
