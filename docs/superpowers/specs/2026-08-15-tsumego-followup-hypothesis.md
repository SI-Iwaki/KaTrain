## 4. follow-up 収束プローブの設計（`followup_concentration_probe.py`）

各ケースで候補初手ペア（不一致: want vs chosen ／ 正解コントロール: want vs
目数同着バンド内 visits 次点）について:

1. 初手 m を打つ → 子局面をリージョン解析（本番と同条件 1800v・wRN=0.04）
   → 相手の応手集中度（reply_v2_v1 等）と最有力応手 r
2. r を打つ → 孫局面を同条件で解析 → **次の同色の手の集中度**
   （fu_v2_v1・fu_pl_gap・fu_v1_share・fu_prior2_prior1、
   dominant 判定は曖昧さ解析と同一: v2/v1 < 0.15 かつ pl_gap >= 1.0）
3. 判断時点の親局面で humanSL 9段 8visits を1本 → 各初手の humanPolicy
   （8/10 spec §10 の宿題「humanPolicy は作意の情報を持つか」の実測を兼ねる）

判定規則（採用可否の事前基準）:
- 別解ペアで P(want の follow-up がより収束) が 50% から有意に乖離 →作意の実信号
- **正解コントロールで同じ規則が want を裏切る率が同程度なら不採用**（シャッフル。
  CLAUDE.md「以前成功していた側の破損率を必ず測る」）

**reply 集中の「有意」は作意ではなく KataGo 順位の裏返し**: alt では want（記録手）は大抵
KataGo 非本命で、control では want（正解＝選択手）が本命。どちらのグループでも
**「ペアのうち KataGo 順位が低いほうの手」が 60〜69% で応手集中に勝つ**＝この指標は
「forcing な手は読まれるが本命にならない」という KataGo の選好を測っているだけで、
アプリの作意とは独立でない。採用すれば control（正解ケース）を先に壊すシャッフル。

**結論**: 体感 (b) は、KataGo リージョン解析で測れる形の follow-up / 応手集中度では
別解ペアを分離しない（8/10 の 62 指標総当たりの結論「別解は盤面に情報が無い」は
子局面・孫局面軸まで拡張しても維持）。体感 (a) は 8/10 実証・対処済み。
このクラスの不一致を消す既存機構は回答帳そのもの。
