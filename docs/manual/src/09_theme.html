09盤面テーマ（盤と碁石のデザイン）

一般・エンジン設定の「盤面テーマ」ドロップダウンで、盤の木目・碁石・線の見た目を切り替えられます。同梱テーマは default / koast / lizzie / milos の 4 つ（元の KaTrain の themes に由来）。 盤の描画はその場で切り替わります。右パネルの背景色やフォントなど盤以外の部分は再起動後に反映されます。

自分でテーマを作る

  • ~/.katrain/themes/<名前>/ にフォルダを作り、theme.json（katrain/gui/theme.py の Theme クラスの属性を上書き）と、差し替えたい画像（board.png / B_stone.png / W_stone.png 等・同梱と同じファイル名）を置くと一覧に出ます。
  • 従来どおり ~/.katrain/theme*.json をベタ置きした設定は常時適用され、その上に選択テーマが重なります。
  • 地合推定の表示スタイル（TERRITORY_DISPLAY: blended / shaded / marks / blocks）や石のマーク（STONE_MARKS: all / weak / none）、色（OWNERSHIP_COLORS）もテーマで変えられます。詳細は THEMES.md。
