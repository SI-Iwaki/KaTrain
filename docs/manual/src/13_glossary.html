付録用語集

用語意味
KataGoKaTrain が使う囲碁 AI エンジン。局面の勝率・目差・候補手を計算します。
モデル（ニューラルネット）KataGo が局面を評価するために使う学習済みの重みファイル（.bin.gz）。通常モデルと humanSL モデルの 2 種類を使います。
humanSL モデル人間の棋譜から「この段級位の人はどこに打つか」を学習したモデル（b18c384nbt-humanv0.bin.gz）。Human-like 系の戦略の土台。
humanPolicyhumanSL モデルが出す「指定した段級位の人間がその手を打つ確率」。高いほど自然な手。本書では「人間らしさ」とも書きます。
policy（第一感）ニューラルネットが読みを入れずに出す「次の一手の確率分布」。KaTrain の「第一感」表示。
visits（探索手数）KataGo が 1 局面で読んだ手数（探索回数）。多いほど正確で遅い。候補手の下の数字（例 2.0k）はその手に費やした visits。
目（目差・scoreLead）地の差。KataGo の「推定目差」は終局時の予想。損失は「最善手と比べて何目損か」。
勝率（winrate）KataGo が推定する勝つ確率。内部では常に黒視点で計算され、表示は手番側に変換されます。
地合推定（ownership）各交点が最終的にどちらの地になるかの推定（−1＝白 〜 +1＝黒）。「未確定点」は絶対値が 0.5 未満の交点。
損失（pointsLost）ある手を打つことで最善手と比べて失う目数。ドットの色の元。
悪手フィルタHuman-like 系の戦略が「損失がしきい値を超える手は人間らしくても打たない」ようにする仕組み。序盤 2.8 目・中盤以降 5.6 目（9路 0.5 / 3.3 目）。
安全弁重み付け抽選で選ばれそうな手が 4 目以上損なら KataGo 最善手に差し替える保険（攻撃型戦略）。
一致率評価レポートの「AI の最善手との一致率」＝打った手が KataGo の最善手と同じだった割合。AI らしさの指標。
ヨセ（終盤）境界を確定させる終盤。戦略ごとの「ヨセ切替手数」以降は棋風の重み付けをやめて最善手か 9 段の第一感に戻ります。
持碁（ジゴ）目差 0 の引き分け。「Kata持碁」は僅差勝ち、「難解」の aim_jigo は持碁〜2 目以内の負けを狙います。
コウダテコウを取り返すために打つ「相手が応じざるを得ない手」。詰碁ではコウダテがある前提で正解が決まるため、KaTrain の詰碁機能もそう評価します。
セキお互いに手を出せず両方生きている形。詰碁の正解の順序は 攻め方: 無条件死 > コウ > セキ、守り方: 無条件生き > セキ > コウ。
枠（詰碁用の外枠）死活問題の周りを石で埋めて、AI が問題に集中できるようにする仕組み（F10）。
df-pn（死活ソルバ）証明数探索という手法で死活を厳密に解くプログラム。KataGo と違い「読み切れれば必ず正しい」が、大きい問題は解けない。
回答帳詰碁の正解手順を記録し、同じ問題（盤の向き違いも含む）が出たら 0 秒で再生する機能。
BlueStacks / ADBWindows 上で Android アプリを動かすエミュレータと、そのアプリをコマンドで操作する仕組み（Android Debug Bridge）。
SGF棋譜ファイルの標準形式。KaTrain は解析結果やコメントも埋め込めます。
