10設定リファレンス

設定ファイルとフォルダ

場所内容
~/.katrain/config.jsonすべての設定（エンジン・一般・対局・AI 戦略ごとの値・詰碁・盤面監視・自動ループ・UI 状態）。GUI の各設定画面はこのファイルを書き換えます。KaTrain 終了後に手で編集可。
katrain/config.json（パッケージ）初期値。「デフォルトに戻す」はここから読みます。
katrain/KataGo/analysis_config.cfgエンジンに実際に渡される KataGo の設定（スレッド数など）。~/.katrain/analysis_config.cfg は参照されません。
~/.katrain/logs/ログ。対局 game_*.log（20 手未満は削除・10 本保持）、詰碁 tsumego_*.log（1 問 1 ファイル・30 本保持・回答帳に記録した問題は保護）、archive/（30 日より古い詰碁ログの zip）、autoloop/（自動ループの失敗スクショ）。
~/.katrain/tsumego_answers.json回答帳。
~/.katrain/tsumego_cache/死活ソルバの永続キャッシュ。
~/.katrain/tsumego_ledger.jsonl自動ループの台帳（1 問 1 行）。
~/.katrain/trtcache/TensorRT のチューニング結果。消すと次回起動が数分遅くなります。
~/.katrain/themes/ユーザー追加の盤面テーマ。

デバッグ出力

一般設定の「コンソールのデバッグレベル」を 1 にすると、AI 戦略が手を選んだ理由（フィルタを通った候補数・安全弁の発動・フェーズなど）がログに詳しく出ます。不具合を報告するときは 1 にして再現し、~/.katrain/logs/ のログを添えてください。確認後は 0 に戻します（ログが大きくなるため）。

対局なしで特定の局面の戦略の判断を再現するコマンドラインツールもあります（開発者向け）:

python -m katrain_debug --sgf 棋譜.sgf --move 30 --strategy hunt --output text
python -m katrain_debug --sgf 棋譜.sgf --strategy enigma13 --batch --player W   # 1局通しの一致率・損失
