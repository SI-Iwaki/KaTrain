メニュー・設定
キー動作
Altメインメニューを開閉
Tab対局／分析モードの切替
Ctrl+N新規対局
Ctrl+L棋譜読込
Ctrl+S / Ctrl+D棋譜保存／名前をつけて保存
Ctrl+C / Ctrl+VSGF をクリップボードへ／から
F5 F6 F7 F8 F9時間設定／指導・分析設定／AI設定／一般・エンジン設定／分散訓練
F2 / F3 / F10一局全体を深く分析／評価レポート／詰碁用の外枠
F12 ` ~最小表示の切替
Escすべての解析を停止
対局・移動
キー動作
pパス
EnterAI に 1 手打たせる
← z / → x1 手戻す／進める（Shift で 10 手、Ctrl で最初／最後まで）
Home / End最初／最後の手へ
↑ / ↓分岐の切替
n / Shift+n次／前の悪手（オレンジ以上）の直前へ
b / Shift+b前の分岐点へ／主分岐へ戻る
c分岐の折り畳み／展開
PageUp選択中の手を主分岐にする
Ctrl+Delete選択中の手以降を削除
Pause時計の一時停止／再開
k / m座標表示／手数表示の切替
分析
キー動作
q w e r t次の着手／ドット／上位候補／第一感／地合推定
a s d f深く分析／均等分析／盤上全手／他の候補
g / h領域を絞る／分析リセット
i / l挿入モード／終局まで自動対局
Space / Shift+Space継続分析の切替（候補表示を ON にしない版）
マウス・グローバルホットキー
操作動作
右パネル上でホイール手を進める／戻す
候補手の上でホイール予想手順を 1 手ずつ進める
候補手の上でホイールクリック予想手順を手順ツリーに追加
着手をクリック／ダブルクリックその手の詳細を表示／その手の直前へ移動
丸い対局者アイコンをクリック黒白を入れ替え
F4 系（設定可）詰碁キャプチャ（自動推定／攻め方／守り方／枠なし）
Ctrl+Alt+D盤面監視のトグル（詰碁の白番監視の停止にも）
Ctrl+Alt+A詰碁の自動ループのトグル
