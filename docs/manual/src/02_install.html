02インストールと初回起動

必要なもの

もの説明
Windows PC ＋ NVIDIA GPUこの改修版は Windows 11 ＋ GeForce RTX（TensorRT 版 KataGo）で開発・検証されています。GPU が無くても CPU 版 KataGo で動きますが、AI の応答は数倍〜数十倍遅くなります。
Python 3.123.9〜3.13 で動作します。uv（Python のパッケージ管理ツール）があると依存ライブラリのインストールが 1 コマンドで済みます。
KataGo 本体囲碁 AI エンジンの実行ファイル（katago.exe）。v1.16 系。
KataGo の通常モデル局面を評価するニューラルネット（例 kata1-b18c384nbt-…bin.gz）。パッケージ同梱の既定パスがそのまま使えます。
humanSL モデル（人間らしさモデル）b18c384nbt-humanv0.bin.gz。これが無いと「Human-like」「力戦派(Human拡張)」「持碁」「難解」など人間らしい戦略はすべて動きません（→ エンジン設定）。

インストール手順

  1. リポジトリのフォルダ（例 C:\Users\<あなた>\Documents\katrain-1.17.1.1\katrain-1.17.1.1）でコマンドプロンプトを開きます。
  2. uv sync を実行して依存パッケージ（Kivy・KivyMD・Pillow など）をインストールします。uv が無い場合は pip install -e . でも構いません。
  3. python -m katrain で起動します。初回は KataGo が GPU 向けにチューニングするため、起動に 1〜2 分かかることがあります（右下のランプが緑になれば準備完了）。
  4. 起動後に F8（一般・エンジン設定）を開き、KataGo・モデル・humanSL モデルのパスを確認します（下記）。
cd C:\Users\<あなた>\Documents\katrain-1.17.1.1\katrain-1.17.1.1
uv sync
python -m katrain

エンジン設定（KataGo・モデル・humanSL モデル）

メニュー（画面左上の ≡ または Alt）→「一般・エンジン設定」（F8）で開きます。 上段が KataGo 設定、下段左が一般設定、下段右がエンジン設定です。

KataGo 設定（上段）
項目何を入れるか
KataGoモデルファイルの場所通常モデル。既定はパッケージ同梱の katrain/models/kata1-b18c384nbt-…bin.gz。「追加モデルをダウンロード」で別のモデルも取れます。
Path to human-like modelhumanSL モデルのフルパス（例 C:\Users\<あなた>\.katrain\b18c384nbt-humanv0.bin.gz）。空のままだと humanSL 系の戦略は「AI設定」に出ていても KataGo 最善手を打つだけになります。
KataGo実行ファイル（フルパス）katago.exe のフルパス。空なら内蔵の OpenCL 版を使います。TensorRT 版を使うならここに指定します。
KataGo設定ファイルの場所既定 katrain/KataGo/analysis_config.cfg（パッケージ同梱）。ここで指定したファイルだけがエンジンに渡されます。~/.katrain/analysis_config.cfg を編集しても効きません。
エンジンコマンドの上書きリモートの KataGo に接続するなど特殊な起動コマンドを丸ごと指定したいとき用。通常は空。
エンジン設定（右下）
項目意味目安
分析時の最大探索手数1 局面あたり KataGo が読む手数（visits）。多いほど正確で遅い。Human-like 系の AI 戦略の内部解析もこの値で動きます。RTX 3080 で 1000〜2000。CPU なら 100〜300
簡易分析時の最大探索手数棋譜読込時の「簡易解析」や盤上全手の分析で使う軽い探索の手数。25〜100
分析の最大時間1 クエリに使ってよい秒数の上限。8
Wide root noise候補手を広く探索させる度合い。0.02〜0.1 で候補手が増えます（強さは少し落ちる）。0.04
地合推定を計算する各交点がどちらの地になるかの推定（ownership）を毎回計算するか。OFF でも必要な戦略は自分で要求します。どちらでも可
設定ファイルの場所 すべての設定は C:\Users\<あなた>\.katrain\config.json に保存されます（ダイアログのタイトルにもパスが出ます）。 KaTrain を起動したままこのファイルを手で編集しないでください。終了時にアプリが設定を丸ごと書き戻すので、編集が消えます。 手で直すときは KaTrain を終了してからにします。
