標準の戦略（元の KaTrain から引き継いだもの）

ここに挙げる戦略は元の KaTrain にもあるもので、humanSL モデルは使いません。設定画面の説明文もそのまま読めますが、設定項目の意味と「上げる／下げる」をまとめておきます。

手加減なし ai:default

全盤サイズ設定項目なしプロ以上の強さ

KataGo の最善手をそのまま打ちます。強さは一般・エンジン設定の「分析時の最大探索手数」とモデルで決まります。分析やドットの評価は、どの戦略を選んでいてもこの「手加減なし」の KataGo が行います。

段級位相応 ai:p:rank

全盤サイズ校正済み15級〜3段

合法手の中からランダムにいくつか候補を選び、その中で最も第一感（policy）の高い手を打ちます。強い設定ほど多くの候補から選ぶので強くなります。GnuGo や Pachi などのボットで校正されており、序盤から終盤まで大ポカをしないバランスの良い弱さが特徴です。相手の強さを合わせたいときの第一候補。

設定項目既定範囲意味上げると／下げると
kyu_rank415級〜3段目標の段級位。級数を上げる（弱く）候補が減り見落としが増える。段側へ強くなる。3段は内部値 −2 に対応

Kata置碁 ai:handicap

全盤サイズ置碁向け

置き石が多い碁で、KataGo が「不利を承知で最も勝ちやすい手」を打つモードです。通常の KataGo は置碁の白番だと投げやりな手を打ちがちなので、置碁で強い相手が欲しいときはこちらを選びます。

設定項目既定範囲意味上げると／下げると
automaticONON/OFF置き石数から pda を自動で決める。OFF にすると下の pda を手で指定
pda0W+3.0〜B+3.0KataGo の playoutDoublingAdvantage（黒から見た有利度の仮定）。B 側へ「黒が有利」と仮定して白が無理気味の勝負手を増やす。W 側へその逆

簡明派 ai:simple

全盤サイズ約2段

「盤面を単純にする手」を好みます。損の少なさに加えて、自分と相手の確定地が増える手・相手の手の近くに応じる手・相手の石にくっつかない手を高く評価します。重視度を負にすると逆に複雑化を目指します。一般設定の Wide root noise を上げると、強さを犠牲にこの基準により忠実になります。

設定項目既定範囲意味上げると／下げると
max_points_lost1.750〜5.0これ以上損な候補は除外（目）。上げる単純化のためにより損な手も打つ＝弱く。下げる最善手寄り
settled_weight1.00〜4.0「確定地を増やす」重視度。上げる地を固める手を強く好む。負なら複雑化
opponent_fac0.5−2.0〜1.0相手の確定地が増えることの重視度（settled_weight との積）。上げる相手にも地を与えて穏やかに。負なら相手の地を荒らしたがる
min_visits31〜30この探索手数未満の候補は無視。上げる読みの浅い手を候補から外して安定
attach_penalty1−1.0〜5.0相手の石に接触する手のペナルティ。上げるツケ・ハネを避ける。負ならくっつきたがる
tenuki_penalty0.5−1.0〜5.0相手の手から縦横 3 間より離れた手のペナルティ。上げるおつきあいして応じる。負なら手抜きしたがる

損も混ぜて ai:scoreloss

全盤サイズ校正済み約4級〜

損する目数に応じた確率でランダムに手を選びます（損が大きいほど低確率）。「小さなミスを時々する」多彩な相手になります。探索手数が多いほど候補が増えて弱くなる点に注意。

設定項目既定範囲意味上げると／下げると
strength0.20〜1損に対する厳しさ。1 でほぼ最善手。上げる強く（損を嫌う）。下げる大きな損も混ざり弱く（0 で約 4 級相当）

第一感 ai:policy

全盤サイズ約5段

一手も読まずに、ニューラルネットの「形の感覚」だけで最有力手を打ちます。読みが無いので石の取り合いやコウで見落としをします。

設定項目既定範囲意味上げると／下げると
opening_moves220〜50序盤の何手目までをよりランダムにするか。上げる布石が毎回変わる。0 で常に同じ布石

第一感（比重） ai:p:weighted

全盤サイズ校正済み

第一感の確率そのままに手を抽選します。小さなミスが多く、読み不足でたまに大ポカもする「らしい」弱さです。

設定項目既定範囲意味上げると／下げると
weaken_fac1.250.5〜3.0弱そうな手を選ぶ度合い。上げる低確率の手も選び弱く。下げる（0.5 付近）ほぼ「第一感」と同じ
pick_override1.00〜1最有力手の確率がこれ以上ならその手を無条件で打つ。下げる「明らかな一手」を見逃さなくなる＝強く
lower_bound0.1%0〜5%この確率未満の手は決して打たない。上げる変な手が減る

第一感（盲点） ai:p:pick

全盤サイズ校正済み

pick_n + pick_frac × 合法手の数 個の手をランダムに選び、その中で最善の手を打ちます。毎手「盤の一部が見えていない」状態になるので、盲点のある弱さを再現します。同じ仕組みで校正した「段級位相応」のほうが使いやすいです。

設定項目既定範囲意味上げると／下げると
pick_override0.950〜1最有力手の確率がこれ以上なら無条件で打つ（明らかなミス防止）。下げる強く
pick_n50〜25候補の固定数。上げる見える範囲が広がり強く
pick_frac0.350〜1候補の割合（合法手数に対する）。上げる強く。1 で「第一感」と同じ

おつきあい派 ai:p:local

全盤サイズ校正済み

「盲点」と同じ仕組みですが、直前の着手に近い手ほど候補に入りやすいようにします。相手の手に必ず応じる、手抜きをしない相手になります。

設定項目既定意味 / 上げると
pick_override0.95明らかな一手はそのまま打つしきい値
stddev1.5「近さ」の広がり（路）。上げると少し離れた手も候補に
pick_n / pick_frac15 / 0候補数。上げると強く
endgame0.5盤のこの割合が埋まったら重み付けをやめ普通に打つ

手抜き派 ai:p:tenuki

全盤サイズ校正済み

逆に直前の着手から遠い手ほど候補に入りやすい。相手の手に応じず大場へ回る「手抜き」だらけの相手です。

設定項目既定意味 / 上げると
pick_override0.85明らかな一手はそのまま打つしきい値
stddev7.5「遠さ」の広がり。上げるとより遠くへ
pick_n / pick_frac5 / 0.4候補数。上げると強く
endgame0.45盤のこの割合が埋まったら普通に打つ

Kataマネ碁破り ai:antimirror

全盤サイズ設定項目なし

相手がマネ碁（自分の手を点対称に真似る）をしている前提で、マネ碁を利用して得をする KataGo のモードです。相手がマネ碁をやめれば普通の KataGo になります。
