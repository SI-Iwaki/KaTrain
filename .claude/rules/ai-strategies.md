# AI 戦略（Human-like AI 拡張）

`katrain/core/ai.py` の戦略クラスを触る前に読む。パラメータの具体値は `ai-parameters.md`、
フィルタ実装の詳細とチェックリストは `ai-humanstyle.md`。

## 改修の全体像

Human-like AI（9段）モードの拡張。悪手フィルタ（スコアベースのフィルタリング）に加え、力戦派（Fighting）・攻城（Siege）・狩猟（Hunt）・狩猟一致率低減（HuntDivergence）・AI一致率低減（Divergence）・地合い勝ち（Jigo）等の戦略モードを追加・改修。力戦派には複雑化モード `complex`（切りボーナス＋リード適応の損失予算ゲートで盤面を紛れさせる）を追加。力戦派の human/complex の悪手フィルタ閾値は **9路と13/19路・序盤と中盤以降で独立した GUI スライダー**（`fighting_human_*_max_loss` / `complexity_*_max_loss_9`、解決は共有純関数 `_fighting_loss_thresholds`）で、既定値は従来のハードコード値と同一。`fighting_max_loss` は scoreloss 専用で human/complex には効かない。Jigo には序盤星打ち強制オプション `jigo_force_sanrensei`（19路のみ・黒=三連星/白=2連星）を追加。さらに Jigo には9路専用の独立戦略 `ai:jigo9`（持碁（9路））を追加（既存 `ai:jigo` は19/13路専用に整理）し、9路 deception の phase 境界・target を5スライダーで調整可能にした（phase3前倒しで挽回を間に合わせる）。星打ち布石ロジックは `ai.py` の共有ヘルパー `_compute_star_opening_targets` に集約し HumanStyle の2連星と共用。さらに**9路専用の独立戦略 `ai:parity9`（一致率追随（9路））**を追加（**終局レポートの AI 最善手一致率を絶対目標 `parity9_target_rate` まで下げつつ勝ちきる**。2026-08-08 に設計を入れ替えた＝実測の経緯と却下案は `.claude/rules/ai-parameters.md` の「改修 2026-08-08」に集約。要点は4つ。(1) **候補プールは通常解析 `cn.candidate_moves`**。Stage2 は `scoreLead` をクリーンに保つため `wideRootNoise=0` で撃っており、9路では非最善手を 69〜86visits でしか読まないので損失が一貫して 1.3〜1.8目楽観的に出る（改修前の低い一致率は損失の過小評価で買っていた）。損失は `relativePointsLost`＝**GameNode 側で既に打つ側視点に符号済み**なので `sign` を掛けない。`PARITY9_MIN_VISITS`(10) 未満は候補に入れない。(2) 解禁は**レートゲート** `parity9_rate_gate`＝「この手も一致させたら実効目標を超えるか」の先読み型で、実効目標は `parity9_target_rate` の**絶対値のみ**（相手の一致率では動かさない＝ユーザー要件の条件は「勝てない場合」で、それは勝率フロアが処理するため二重適用だった。実測で30判断中5回、安全性と無関係にゲートを閉じていた）。旧・一致数差ゲートは 0-0 で必ず閉じるため**盤面で最も外し賃の安い白の初手**を落としており、相手が最善手に一度も一致しない対局では追随目標が原理的に達成不能だった。(3) 安全条件は**着手後の勝率フロア** `parity9_min_winrate` **ただ1つ**（候補の `winrate` は探索値＝相手の最善応手込み）。スコア予算 `lead − keep_margin` は撤去した＝`scoreLead` は komi 込みなので「lead > 0」は「勝率 > 50%」と同義で、**9路 komi 7 の黒は開始時点で lead が負**（実測 黒番実戦 depth 0〜8 で −0.22〜−0.04）＝予算 0 で早期 return し、勝率フロアが評価されないまま「no budget」とログに出る**黒白非対称**だった。hp を見ない足切り `parity9_has_admissible` を挟むことで「外すと決まるまで humanSL を撃たない」順序は維持している。なお**序盤を塞いでいるのは予算ではなく勝率フロア**（黒の序盤は勝率50%ちょうどなので、勝率を下げたくないなら原理的に外せない）。(4) 選択は**最安バンド内の humanPolicy 最大**（`parity9_cost_slack`）。「予算内で humanPolicy 最大」だと毎回予算を使い切るが、実測では高価な外しほど humanPolicy も低いので安さを第1基準にするとコストと不自然さが同時に下がる。pass は外し候補から除外するので area scoring のダメ処理は KataGo 最善手のまま。ヨセ（`parity9_endgame_move` 手数以降 **かつ** 未確定点 `|ownership| < 0.5` が `parity9_unsettled_max` 以下）に入ったら sticky はユーザーのローカル設定が `_enable_ownership: false` なのでクエリで明示要求する。全ゲートが「最善手を打つ」に倒れるフェイルセーフ）。さらに**9路専用の独立戦略 `ai:enigma9`（難解（9路））**を追加（2026-08-10・spec `2026-08-10-enigma9-strategy-design.md`。序盤〜中盤は損失上限 `enigma9_max_loss`〈候補値の天井1.8目＝**2目以上の損失手は打たない**〉と着手後勝率フロア `enigma9_min_winrate` の内側で「**相手が正しく応じることが最も難しい手**」へ積極的に外し、相手の研究した定跡・手筋を無効化する。難解さは候補ごとに子局面をプローブ〈クリーン500visits + humanSL 9段 humanPolicy
